📌 Fafanua: Ndani ya kasha la kompyuta (System Unit), kuna vifaa vikuu vinavyofanya kazi kama viungo vya mwili wa binadamu. Hebu tuvijue kimoja kimoja kwa mifano halisi ya maisha yetu.

7) Important Computer Hardware Components :

There are some main hardware components that work

together to make the computer run smoothly. Let's learn

about each component.

🧠 Ubongo wa Kompyuta: Kama vile rubani wa ndege au dereva mkuu wa treni anavyoamuru safari nzima, CPU ndiyo inafanya mahesabu yote na kutoa amri kwa kila kifaa.
Ushauri wa NECTA: Taja kuwa inafanya hatua 3: Fetch (kuchota amri), Decode (kuchambua) na Execute (kutekeleza).

1. CPU (Central Processing Unit) :

CPU is called the brain of the computer. It

processes data, performs calculations and

controls all the activities of the computer.

It fetches instructions from memory, processes

them and gives the result.

Example : Intel Core i3, i5, i7, AMD Ryzen.

🛣️ Ubao Mama (Soko Kuu / Barabara Kuu): Ni sawa na Barabara Kuu inayounganisha mitaa yote. Vifaa vyote kama CPU, RAM na Diski vinachomekwa hapa ili viwasiliane bila kikwazo.
Gusa vitone vyekundu (hotspots) kwenye mchoro kuchunguza vinavyochomekwa!

2. Motherboard :

The motherboard is the main circuit board of the

computer. It connects all the hardware components

like CPU, RAM, Storage devices and other parts so

they can work together.

Example : ASUS, Gigabyte, MSI.

🪚 Meza ya Fundi Seremala (Workbench): Fundi huweka mbao anazochonga sasa hivi hapa mezani. Akizima taa au akiondoka (power off), meza inafutwa safi! Ndiyo maana inaitwa Volatile / Temporary Memory (Kumbukumbu ya Muda).

3. RAM (Random Access Memory) :

RAM is a temporary memory. It stores data and

instructions that are currently being used. When

we turn off the computer, the data in RAM is lost.

RAM helps the computer to work faster.

Example : 4GB, 8GB, 16GB, 32GB.

🌾 Ghala Kuu la Kudumu (Storehouse): Kama vile ghala la kuhifadhia magunia ya mahindi. Picha, video na miziki yako inahifadhiwa hapa kwa usalama hata umeme ukikatika (Non-Volatile Storage).

4. Storage Devices :

Storage devices are used to store data, programs

and files permanently. Even when we turn off the

computer, the data remains stored.

Example : Hard Disk, SSD, Pen Drive, Memory Card,

CD / DVD.

⚡ Transfoma ya Kompyuta: Umeme wa TANESCO ukutani (240V AC) una nguvu kubwa ya kuunguza vifaa. SMPS inabadilisha umeme huo na kuushusha kuwa 12V na 5V DC salama kwa ubao mama na diski.

5. Power Supply (SMPS) :

The power supply converts the high voltage electricity

from the main supply to low voltage DC power which

is required by the computer components.

Example : SMPS (Switched Mode Power Supply).

📌 Vifaa vya Pembezoni (Peripherals): Ni sawa na milango ya fahamu ya binadamu (macho, masikio na mdomo). Vifaa hivi vinamwezesha mtumiaji kuwasiliana na kompyuta kwa kuingiza maagizo na kupokea majibu.

8) Input and Output (I/O) Peripheral Devices :

Peripheral devices allow users to communicate with the

computer by feeding instructions and receiving processed results.

⌨️ Kibodi: Kifaa cha msingi cha kuingizia maandishi, namba na amri. Ina vitufe 104 kwa mpangilio wa kawaida wa QWERTY.

1. Keyboard (Input Device) :

A keyboard is the primary input device used for

typing text, numbers, and commands into the system.

A standard QWERTY keyboard has 104 keys.

Keys : Alphanumeric, Function (F1-F12), Control keys.

🖱️ Kipanya cha Macho: Kifaa kinachomwezesha mtumiaji kuelekeza na kubonyeza vitu kwenye skrini kwa kutumia miale ya mwanga (Optical sensor).

2. Optical Mouse (Pointing Device) :

The mouse is a hand-held pointing input device that

controls the cursor movement on the display screen.

It performs left-click, right-click, dragging and scrolling.

Types : Wired USB Mouse, Wireless Bluetooth Mouse.

🖥️ Kioo cha Kompyuta (VDU): Huonyesha taarifa zilizochakatwa kwa mfumo wa maandishi au picha laini (Soft Copy) usizoweza kuzishika mkononi.

3. Monitor / VDU (Output Device) :

Monitor (Visual Display Unit) is the main output

device that displays processed information, images,

and videos in soft-copy visual form on the screen.

Example : LCD, LED, OLED, Curved Gaming Monitors.

🖨️ Kichapishi (Printer): Hutoa matokeo magumu kwenye karatasi halisi (Hard Copy). Kasi yake hupimwa kwa idadi ya kurasa kwa dakika (Pages Per Minute - PPM).

4. Printer (Hard-Copy Output) :

A printer takes digital documents and graphics from

the computer and prints them onto physical paper.

Speed is measured in PPM (Pages Per Minute).

Example : Laser Printer, Inkjet, Dot-Matrix Printer.

5. Scanner & Audio Speakers :

A scanner converts paper documents into digital images,

while speakers convert digital audio signals into sound waves.

Note : Touchscreen acts as both Input & Output device!

🌐 Topolojia ya Mtandao: Ni jinsi kompyuta na nyaya za mtandao wa ndani (LAN) zilivyopangwa kijiometri kwenye ofisi, shule au maabara.

9) Network Topologies (Physical Layout) :

Network topology refers to the geometric arrangement of

computers (nodes) and cables in a Local Area Network (LAN).

⭐ Topolojia ya Nyota: Kila kompyuta imeunganishwa moja kwa moja kwenye Switch au Hub ya kati. Kebo ya mwanafunzi mmoja ikikatika, wengine wote wanaendelea kupata mtandao vizuri!

1. Star Topology :

All nodes are individually connected to a central

device called a Hub or Switch. If one cable fails,

only that computer is affected, making it very reliable.

Used in : Modern Offices, Schools, Home Wi-Fi LANs.

🚌 Topolojia ya Basi: Kama basi la abiria linalosafiri kwenye barabara kuu moja ya lami (Backbone). Njia hiyo ya kati ikikatika, basi zima linasimama na mtandao wote unakufa!

2. Bus Topology :

Every computer connects to a single shared main

cable called the Backbone. It is inexpensive and easy

to install, but if the main cable breaks, the network stops.

Components : Coaxial Cable, T-Connectors, Terminators.

⭕ Topolojia ya Pete: Kompyuta zimejipanga kwa duara. Taarifa husafiri mwelekeo mmoja tu kwa kutumia pasi maalum (Token). Hakuna data zinazogongana!

3. Ring Topology :

Nodes are connected in a closed circular loop where

each device has exactly two neighbors. Data travels in

one direction using a special control frame called a Token.

Advantage : No data collisions even under heavy traffic.

🕸️ Topolojia ya Wavu (Mesh): Kila kompyuta imeunganishwa moja kwa moja na kompyuta nyingine zote. Salama zaidi hata nyaya kadhaa zikikatika, lakini gharama yake ya nyaya ni kubwa sana: n(n-1)/2.

4. Mesh Topology :

Every node is directly interconnected with every other

node. Total cables required = n(n - 1) / 2. Highest fault

tolerance and security, used in military and core Internet.
