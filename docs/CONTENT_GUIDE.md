# Content guide
- Topics live in `study/content.js`. Run `npm run validate` after editing.
- Every topic needs a syllabus `code`, a Swahili title, a Swahili entry for each `[[term]]`, a lab of a known type, and ≥ 3 quiz questions.
- English notes stay exam-faithful; Swahili is a margin layer. All Swahili is unreviewed until a teacher signs off.
- Use local contexts (TZS, daladala, school marks). No real people, brands or invented statistics.
- Code samples must run on `study/interp.js` (`npm test`).
